### 2.3 훅 반환값 동작 검증

| 반환값 | boolean | Gateway 처리 | 메시지 흐름 |
|--------|---------|-------------|------------|
| `{}` | **False** | pass-through | 계속 전달 ✅ |
| `None` | **False** | pass-through | 계속 전달 ✅ |
| `{"action": "skip"}` | **True** | 드랍 | 메시지 제거 ✅ |
| `{"action": "rewrite", "text": "..."}` | **True** | 교체 | text 수정 후 전달 |

### 2.4 일반 대화 메시지 처리 경로

```
Telegram 메시지 수신
        │
        ▼
┌─────────────────────┐
│ pre_gateway_dispatch │
└─────────────────────┘
        │
        ▼
   text.startswith('/')?
        │
   ┌────┴────┐
   │         │
  YES       NO
   │         │
   ▼         ▼
┌────────┐  ┌──────────┐
│ 명령어 │  │ {} 반환  │
│ 파싱   │  │ pass-    │
└────────┘  │ through  │
            └──────────┘
```
